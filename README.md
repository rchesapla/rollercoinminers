# 🚀 RCHesapla - Mağaza & Miner Listesi

**RCHesapla Mağaza**, RollerCoin oyuncuları için madenci (miner) verilerini listelemek, filtrelemek, güç/bonus analizleri yapmak ve envanter takibini kolaylaştırmak amacıyla geliştirilmiş dinamik bir web aracıdır.

🔗 **Canlı Proje:** [https://rchesapla.github.io/sayfa/magaza/](https://rchesapla.github.io/sayfa/magaza/)

---

## ✨ Özellikler

* ⚡ **Güç ve Bonus Analizi:** Miner'ların yalın gücü (GH/s, TH/s, PH/s, EH/s), verdiğin bonus yüzdesi ve hesaplanmış **Bonuslu Güç** değerleri.
* 🔍 **Gelişmiş Filtreleme:**
  * **Nadirliğe Göre:** Common, Legacy, Uncommon, Rare, Epic, Legendary, Unreal.
  * **Pazar/Mağaza Durumuna Göre:** Pazarda satılabilir / satılamaz durum filtresi.
  * **Sahipliğe Göre:** Odada var / yok durumu.
  * **Koleksiyona Göre:** Özel koleksiyon gruplandırmaları.
* 👤 **Kullanıcı/Oda Envanter Takibi:** Kullanıcı adı aratılarak hesap/oda durumuna göre miner'ların var/yok kontrolü.
* 📊 **Detaylı Görünüm:** Miner görselleri, seviye (LVL) bilgisi ve toplam listelenen/gösterilen miner sayaçları.

---

## 🛠️ Teknolojiler

* **Frontend:** HTML5, CSS3, JavaScript / Vue.js (veya AngularJS/Framework bileşenleri)
* **API / Veri Kaynağı:** RollerCoin miner ve pazar veri yapıları
* **Font & Icon:** Google Fonts, Font Awesome / Line Icons
* **Hosting:** GitHub Pages
